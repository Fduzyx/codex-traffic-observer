# 隐私与权限

查看器只读用户选择的本地监测目录，以及明确指定的可选 Mihomo 账本；不调用模型、不访问互联网、不监听端口，也不控制任何工作负载。数据采集与查看是两个独立命令。

Unknown 服务细分使用 SQLite `mode=ro` 与 `query_only`，短事务、有限行数和查询截止时间；缺少必要 WAL 侧文件时跳过，不创建或修复原数据库。只选择既有流量表的时间、目标、来源、进程标签、出口和计数字段。来源 IP、非白名单域名和节点名称仅在内存转为查看器生命周期内的 HMAC 别名；界面不反查 DNS，也不读取认证配置。

同期工作负载关联只使用进程快照中既有的安全字段，不读取命令行、提示词或会话。并发候选形成一个组合组，不把同一字节重复计给多个应用。未知原始进程身份仍未确认，活动共现不会提升为连接归属。

公开版 Windows 采集器仅使用系统已有元数据和可选的本地 Mihomo SQLite 账本。它不读取进程完整命令行、环境凭据、浏览器文件、私人代码、提示词、对话或响应正文。进程路径只用于内存中的产品类别与父子关系判断，输出类别而非私人完整路径。不会安装驱动、证书或服务。

数据库只读查询和本机计数器也可能失败。权限不足、文件锁定、字段缺失、计数回退时，工具保留缺口，不尝试提权或修复。监测器不能保证记录在两个采样点之间就结束的短进程或连接。

在共享截图和报告前检查其中的 PID、活动时间、项目标签与本地目录。它们可能仍然属于敏感的使用元数据。代码中的忽略规则与发布检查是防误提交措施，不能保证用户主动添加的所有文件自动匿名。

禁止将真实采集目录作为 Git 仓库。仓库附带的数据均为人为构造的演示记录，仅用来检查界面与算法，不代表任何人的使用情况。公开版默认不包含个人自动化任务的路径匹配或专用日志适配器。

本工具不会自动限流、暂停、重启或终止 Codex/CLI/WSL/代理，也不修改 DNS、路由、系统代理、网卡或防火墙。所有可能改变工作负载的处置都在工具范围之外。
